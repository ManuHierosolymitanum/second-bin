# הסל השני

סל מחזור לסל המחזור של הגלריה באנדרואיד. האפליקציה שומרת עותק של כל תמונה וסרטון, כך שגם אחרי שמרוקנים את סל המחזור של הגלריה אפשר להחזיר אותם.

## הורדה
**[⬇ להורדת האפליקציה (second-bin.apk)](https://raw.githubusercontent.com/ManuHierosolymitanum/second-bin/main/second-bin.apk)**

## התקנה
1. פותחים את הקישור למעלה בטלפון ומורידים.
2. לוחצים על הקובץ שירד ובוחרים "התקן". אם הטלפון שואל, מאשרים "התקנה ממקורות לא ידועים".
3. אם מופיעה אזהרה של Play Protect: "פרטים נוספים" ← "להתקין בכל זאת".
4. באפליקציה: נותנים גישה לתמונות ("לאפשר הכול") ו"גישה לכל הקבצים", כדי שהעותקים יישארו גם אם האפליקציה נמחקת.

## עדכונים
כפתור ⟳ באפליקציה בודק אם יש כאן גרסה חדשה ומתקין אותה.

## קוד
הקוד נמצא בתיקייה `source/`. `build.sh` בונה את ה-APK בלי Android Studio.
